How to use DocSearch

A quick and easy guide to manage your documents

Searching

You can search your documents in two ways. Use the toggle next to the search bar to switch modes:

  • Content Search: Looks for keywords inside the actual text of your document.
  • Filename Search: Looks only at the names of your documents.

Uploading & Renaming

You can upload one document, multiple documents at once, or a ZIP file containing supported formats.

  • Renaming: Type your desired name in the text box before you select the documents.
  • Uploading Multiple Documents: You can add them one by one. Type a name → Select Doc A. Type a new name → Select Doc B. Finally, click Start Upload to upload them all.
  • ZIP Handling: It automatically extract ZIPs. If you provide a name (e.g., "ProjectX"), the inner files will be named like "ProjectX_report.pdf".

Managing Documents

To organize or delete files, open the My Files tab:

  • Click View to open a document, or click Select to enter edit mode.
  • Select the documents you want to remove and click Delete to permanently remove them from the database.
